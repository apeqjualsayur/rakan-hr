# Rakan

HR and payroll for Malaysian healthcare and therapy centres: staff records, practitioner credential tracking, leave, attendance, claims, and payroll that follows Malaysian law (EPF, SOCSO, EIS, PCB, Employment Act 1955, PDPA).

**Status:** planning complete, build not started.
